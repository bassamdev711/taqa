# طاقة هوم | TAQA HOME

طاقة هوم متجر عربي فاخر للأجهزة المنزلية الكهربائية وحلول الطاقة الشمسية. تعتمد التجربة على لغة بصرية هادئة ومعمارية، ومواصفات واضحة، وبنية تجارة إلكترونية تحافظ على السلة والدفع والطلبات والمصادقة ولوحة الإدارة.

## نطاق المنتجات

يشمل الكتالوج الغسالات، والثلاجات، وأجهزة المطبخ، وغسالات الصحون، وأجهزة التنظيف، والتكييف والتهوية، والسخانات والمياه، والطاقة الشمسية، وتخزين الطاقة، والإضاءة والأدوات الذكية.

يحتوي الكتالوج التجريبي على عشرة تصنيفات ومئة منتج، بواقع عشرة منتجات لكل تصنيف. وتوجد الصور التجريبية محلياً بصيغة SVG داخل `public/products/`.

## التقنيات

- Next.js 16.3.1 مع App Router وTypeScript
- Prisma 5.22 مع PostgreSQL
- Tailwind CSS v4
- Framer Motion وLucide React
- واجهة عربية أولاً باستخدام خط Tajawal
- نشر على Vercel مع دعم اتصال PostgreSQL مباشر اختيارياً

## الأوامر الأساسية

```bash
npm install
npm run dev
npm run lint
npm run build
```

## تهيئة قاعدة البيانات

ينفذ أمر البناء `prisma generate`، ثم يطبق مخطط Prisma الحالي عند توفر اتصال قاعدة البيانات، ثم يبني تطبيق Next.js. يفضل غلاف الاتصال المتغير `DIRECT_URL`، ويعود إلى `DATABASE_URL` عند عدم توفره.

لتهيئة الكتالوج التجريبي من جهاز يحتوي على المشروع ومتغيرات قاعدة البيانات:

```bash
npm run db:bootstrap:demo
```

إذا كنت تعمل من لوحة Vercel فقط، أضف المتغير `SEED_DEMO_DATA=true` إلى بيئة Production ثم أعد النشر مرة واحدة. سيقوم البناء بإنشاء الجداول وإضافة عشرة تصنيفات ومئة منتج تجريبي. عطّل المتغير بعد نجاح deployment حتى لا يعاد تشغيل seed في كل بناء لاحق.

لا ترفع ملفات `.env` أو بيانات اتصال قاعدة البيانات إلى GitHub. راجع [SETUP.md](./SETUP.md) للتعليمات التفصيلية الخاصة بـ Vercel وPrisma.
